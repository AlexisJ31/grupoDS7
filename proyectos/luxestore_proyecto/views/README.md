# Arquitectura MVC en este proyecto

Esta carpeta contiene la parte de `views` del proyecto.

## Estructura actual

- `controllers/` - scripts que controlan el comportamiento de la aplicación.
- `models/` - modelos de datos o lógica de negocio.
- `views/` - archivos HTML que representan la interfaz de usuario.
- `views/pages/` - páginas secundarias del sitio.
- `routes/` - rutas de la aplicación (estructura preparada).
- `config/` - configuración del proyecto.

## Uso

- `views/index.html` es la vista principal.
- `views/pages/` contiene las vistas de las páginas internas.
- `controllers/main.js` contiene la lógica de interacción del front-end.

> Esta organización es sólo de estructura; no se han modificado los contenidos funcionales originales.
